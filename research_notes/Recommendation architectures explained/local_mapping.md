# Local architecture mapping

All settings below describe local implementation, not independently verified paper specifications. Sources are relative to `C:/Users/janam/Desktop/MLG/graph-tiger-recsys/`.

- **Shared text input:** `scripts/paper/embed_items.py:14` defaults to Sentence-T5-base; `:34` builds title/price/brand/categories text, `:44` encodes it. README `:83` confirms output dimension 768 and official-RPG substitution PCA128. This text encoder is pretrained; downstream recommendation Transformer is initialized from configuration, not loaded pretrained.

- **TIGER tokenization:** `scripts/paper/rqvae.py:45` encoder 768→512→256→128→32; decoder reverses it. Three residual levels, each 256 learned 32-dimensional code vectors (`:15`, `:48`), nearest residual lookup/subtraction (`:50`), reconstruction+quantization/commitment training (`:61`, `:83`). Three learned digits plus a deterministic collision index make four-token IDs (`:95`). Alternative `rkmeans.py:14` uses three residual k-means levels directly on input vectors, plus collision token (`:23`). This alternative is a local comparison, not RQ-VAE.

- **TIGER predictor:** `src/tiger/model.py:9` and `scripts/paper/train_t5.py:47`: randomly initialized T5, encoder4/decoder4, hidden128, six attention heads with per-head key/value64, FF1024, dropout0.1; embeddings untied. T5 supports attention projection width6×64 despite hidden128. `src/tiger/data.py:11`, `:220` flattens up to20 historical products×4 codes, prepends hashed user token (2000 buckets), predicts next4 codes plus EOS. Default200k steps, run_all actual30k (`train_t5.py:60`, `run_all.sh:26`).

- **RPG-style local:** `scripts/paper/pgen.py:27` PCA128→OPQ/product quantization, default32 digits, each256 values (`:42`, `:58`). `--digits` is configurable; no64 default or shell invocation found. Product's32 code embeddings are averaged into one448-dimensional input (`:90`, `:105`). Random GPT2 architecture: two causal layers, four heads, FF1024, history50 (`:35`, `:91`). Separate residual prediction head per digit; tied normalized code embeddings yield32×256 parallel logits (`:95`, `:114`). Training sums token classification; evaluation scores every catalog item's known code by summed log probabilities (`:140`), rather than implementing official RPG semantic-ID graph decoding.

- **Graph addition:** `lightgcn5.py:16` dim64/two propagation layers; only training edges (`:33`); BPR training. `src/lightgcn.py:35` averages embeddings from layers0,1,2. Saved item vectors are loaded/fixed in pgen, projected64→448 and added with scalar or per-dimension sigmoid gate (`pgen.py:66`, `:98`, `:105`). This user-item graph differs from official RPG's semantic-ID decoding graph.

- **ACE-inspired:** `scripts/paper/ace.py:26` default mean pooling, one latent; `--atm --latents K` enables attention merger. Learned queries from item summary attend over32 code embeddings (`:112`). Optional intent appends summary token (`:174`); two custom causal blocks/four heads/448 hidden default (`:41`, `:96`). Parallel prediction heads remain. Optional ISA contrastive item alignment adds to token CE (`:245`). Flags are off by default.
